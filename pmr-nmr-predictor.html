📖 The Four Rules of PMR Interpretation (reference)

1Number of Signals

Chemically equivalent protons give one signal. Count different environments, not total H atoms.

2Chemical Shift (δ)

Position (ppm) shows the proton's environment. More deshielded (near O, N, halogen, C=O, ring) → higher ppm.

3Integration

Area under each signal ∝ number of protons responsible for it. Expressed as a simplest-whole-number ratio.

4Splitting — (n+1) Rule

Number of peaks in a signal = n + 1, where n = number of equivalent neighbouring protons.
